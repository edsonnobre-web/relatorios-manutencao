Relatórios de Manutenção V7 PWA

Como testar no celular:
1. Hospede esta pasta em um servidor HTTPS.
2. Abra o link no Chrome/Edge do celular.
3. Toque em "Instalar app" ou use o menu do navegador > "Adicionar à tela inicial".
4. O app abrirá como aplicativo e funcionará com cache offline.

Observação: PWA não instala corretamente abrindo diretamente o arquivo HTML local (file://). É necessário HTTPS ou localhost para teste.
